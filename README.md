## Sobre o projeto

O **BeatPy** é um jogo de ritmo em 4 teclas desenvolvido em Python usando **PyGame**, inspirado em jogos do estilo **VSRG** como *osu!* e *Etterna*.
O objetivo é acompanhar o ritmo da música acertando as notas no tempo correto utilizando o teclado.

O jogo possui diferentes músicas e dificuldades, além de um sistema de alteração dinâmica de velocidade para deixar a experiência mais desafiadora e personalizável.

As músicas e mapas utilizados foram importados do **Osu!**, servindo como base para adaptação do nosso próprio sistema e jogabilidade.

## Controles

* **D F J K** → teclas utilizadas para jogar

## Como rodar o jogo

1. Instale o Python 3.10+
2. Instale as dependências:

   ```bash
   pip install pygame
   ```
3. Clone o repositório:

   ```bash
   git clone https://github.com/seuusuario/seurepositorio.git
   ```
4. Execute o jogo:

   ```bash
   python main.py
   ```

## Uso de IA

Durante o desenvolvimento utilizamos o **Microsoft Copilot** como ferramenta de apoio, principalmente para acelerar a criação de algumas partes do código e da interface gráfica.

As sugestões fornecidas pela IA foram revisadas e modificadas manualmente conforme a necessidade do projeto. Em vários momentos os códigos apresentavam erros ou não funcionavam da maneira esperada, então foi necessário ajustar lógica, corrigir bugs e reorganizar partes importantes do sistema.

Grande parte da estrutura visual do jogo começou a partir de ideias sugeridas pelo Copilot, mas foi alterada e adaptada pelo grupo para combinar melhor com o estilo do projeto.

## Créditos
